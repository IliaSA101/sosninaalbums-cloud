# sosninaalbums-cloud

Сервис онлайн-листалок для настольной программы Sosnina Albums. Фотограф собирает альбом в программе и
кнопкой «Выгрузить» отправляет развороты сюда; сервис хранит их и отдаёт ссылку на листалку для клиента
(по желанию — с паролем и сроком).

Состояние: в разработке, готового релиза пока нет.

Стек: сервис на Go без базы данных, Caddy (TLS, статика, проверка пароля), Podman rootless + Quadlet,
Debian 13, развёртывание через OpenTofu → Ansible, резервные копии restic.

## Проверки

- `scripts/check.sh` — все проверки одной командой (`--race` — гонки, `--vuln` — уязвимости зависимостей).
- `node scripts/precheck.mjs` — быстрая проверка изменённых файлов.
- `node scripts/ci-push.mjs <имя> --push` — прогнать проверки в GitHub Actions: из дерева текущего коммита
  строится коммит-сирота (без истории) и отправляется в ветку `ci/<имя>`. Без `--push` команда только
  печатается; `--delete <имя>` убирает ветку. Отправлять только из основной рабочей копии с подключёнными
  хуками (`git config core.hooksPath scripts/git-hooks`): в рабочей копии агента (worktree) pre-push всегда
  отказывает — там нет стража содержимого, а скрипт без хуков публиковать отказывается.
