# Журнал развилок 0.1

Решения оркестратора без вопроса владельцу: вопрос → варианты → выбор → почему. Владелец просматривает
журнал перед выпуском версии; несогласие — переделка в следующей версии.

## 29.10.2026 — проверка только под Linux

Вопрос: нужна ли пара `check.sh` + `check.ps1`, как в настольных проектах.
Варианты: а) обе; б) только `scripts/check.sh`.
Выбор: б. Почему: сервис собирается и работает только в Linux-контейнере; второй сценарий проверки
расходился бы с первым без пользы.

## 29.10.2026 — линтер без исключений путей и прав

Вопрос: оставлять ли привычные исключения `gosec` G301/G302/G304/G306 (права каталогов и файлов,
путь из переменной).
Варианты: а) оставить, как в настольных проектах; б) убрать.
Выбор: б. Почему: сервис пишет на диск файлы, пришедшие из сети, по путям из запроса — это ровно те
места, где ошибка становится уязвимостью. Ложное срабатывание закрывается точечно с причиной.

## 29.10.2026 — модуль контракта подключается позже

Вопрос: подключать ли модуль контракта `/v1` (`api/albums` настольной программы) в `go.mod` сейчас.
Варианты: а) `replace` на локальный путь сейчас; б) когда модуль появится.
Выбор: б. Почему: модуль ещё не создан, `replace` на несуществующий путь ломает сборку. Для публичной
сборки нужна выпущенная версия модуля (метка `api/albums/v0.1.0`) — это решение владельца программы.
